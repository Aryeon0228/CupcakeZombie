정식 웹에 통합최신 버터 반응·좀비 뽀잉·곰팡이 선·결과창·흰 눈 좀비는 검토용 주소에서만 볼 수 있었어요.정식 cupcake-zombie/에도 통합했어요. 클로드의 main을 확인해 로고 원본과 압축한 신선한 블루베리·시나몬롤, 소리 즉시 끄기 수정을 유지했어요. 일반 게임 빌드를 사용하므로 검토용 판 선택 바가 없고, 기존 cupcake-zombie-v3 진행 저장과 스테이지 잠금이 그대로 이어져요.
흰 동태눈 좀비 11종기존 6가지 맛은 공통 좀비로 변했고, 맛별 좀비의 눈 표현도 달랐어요.초코 머핀·딸기·스프링클·체리·휘핑크림·버터에 전용 좀비를 추가하고, 얼그레이·레몬요거트·에스프레소·블루베리·시나몬롤은 가운데가 하얗게 빈 눈의 승인본으로 교체했어요. 게임과 도감 뒷면이 같은 그림을 쓰며, 발 기준점과 변신 뽀잉을 유지해요. 전용 좀비는 좌우 반전을 하지 않아 버터 글씨도 바르게 보여요. 이전 좀비 7장은 assets_extended/zombie-white-eyes-v1/originals에 보관했어요. 민트초코의 벽 규칙과 레몬의 중간 상태는 유지하고, 말차는 콘셉트로만 남겨두었어요.
결과창 버튼 정리하단에 ‘판 보기’가 따로 떨어져 있고, ‘다음 스테이지’ 버튼이 좁아 두 줄로 꺾였어요.‘판 보기’는 결과창 오른쪽 위의 작은 닫기 표시로 옮겼어요. 표시 크기는 16px, 실제 누르는 영역은 44×44px이며 화면 읽기용 이름은 한·영으로 제공해요. 닫기에는 탄성 효과를 넣지 않고, 다음·다시 하기 등 주요 버튼은 넓히고 기존 탄성을 유지해요. 결과를 닫아도 현재 진열대와 진행 기록은 유지돼요.
큰 곰팡이 그림컵케이크에 비해 곰팡이의 갈색 윤곽선이 가늘었어요.작가가 선택한 선 보강 수정본으로 교체했어요. 승인된 고해상도 원본은 assets_extended/mold-outline-v2에 보관하고, 게임용은 기존 240×237 투명 캔버스에 맞췄어요. 하단 표시 크기와 발사할 때의 반동은 그대로 유지해요.
좀비 변신 뽀잉포자를 맞은 반응이 대부분 끝난 뒤 좀비 그림으로 바뀌어, 변신 직후에는 거의 움직이지 않았어요.좀비 그림이 나타나는 순간부터 380ms 동안 한 번 납작해졌다가 길어지고 제자리로 돌아와요. 발 기준점은 고정하고 대기 중에는 멈춰요. 실제 감염되는 모든 맛에 공통 적용하며, 버터 뚜껑 벗기기와 레몬의 차가워진 중간 상태에는 변신 반동을 넣지 않아요. 뒤늦은 추가 타격은 기존 타격 반응이 우선하고, 동작 줄이기 설정에서는 크기를 바꾸지 않아요. 반응실의 ‘변신 뽀잉’에서 느리게 비교할 수 있어요.
포자 미리보기작은 포자가 얼굴을 가리고 가는 점선과 섞여, 도착 대상이 잘 드러나지 않았어요.미리보기의 포자 배지를 제거하고, 첫 전파가 영향을 주는 컵케이크에 크림색·올리브색 외곽선을 넣었어요. 점선은 그림 뒤에서 출발점 → 목적지로 흐르고, 옅은 받침 선으로 배경과 구분돼요. 선택한 컵케이크는 금색 받침으로 표시해요.
미리보기 판정그 컵케이크가 상했다고 가정한 경로를 표시했어요.직접 포자를 맞았을 때 곧바로 나오는 첫 전파를 실제 규칙으로 계산해요. 버터 뚜껑·차가워지는 레몬은 첫 전파를 약속하지 않고, 강한 포자가 포장된 좀비에게 주는 영향은 표시해요. 턴 전체의 최종 연쇄를 보여주는 기능은 아니에요.
선택 반응 시안전체 그림이 잠깐 눌렸다가 돌아왔어요.초코 머핀과 뚜껑을 쓴 버터를 누르면 팔과 눈이 따로 움직여요. 버터는 작가가 분리한 몸통·양팔·눈 4장을 원본 그대로 사용해요. 몸통의 평소 눈을 유지하고 큰 눈은 같은 위치에 잠깐 겹쳐 놀람을 표현해요. 발 위치와 몸통 뽀잉은 유지하며 460ms 안에 멈춰요. 뚜껑이 벗겨진 버터와 나머지 맛은 기존 반응이에요. reaction-lab.html에서 맛을 바꾸고 뽀잉·팔·눈을 따로 비교할 수 있어요.
포자 낙하화면 위부터 좌우로 흔들리며 내려오고, 닿기 직전에 감속했어요.목표에서 최대 2.5칸 위에서 내려와 가속해요. 낙하는 520 → 420ms, 좌우 흔들림은 0.18 → 0.035칸으로 줄였어요.
착지 연결낙하 포자가 접촉 후에도 남고, 착지용 포자가 따로 생성되어 잠깐 겹쳤어요.포자 한 개가 낙하부터 착지까지 담당해요. 아래 접점이 고정된 채 둥근 그림 → 눌린 그림 → 회복을 연결하고 260ms에 걸쳐 마무리해요.
접촉 효과큰 먼지 16개와 비교적 큰 잡음이 한꺼번에 났어요.작은 먼지 7개와 짧은 저음의 톡 소리로 접촉을 알려요. 포자 표시 크기도 0.405 → 0.32칸으로 줄였어요.
연쇄 효과음동시에 감염된 컵케이크마다 소리가 겹쳤어요.45ms 안의 연쇄 음은 하나로 묶고 전체 음량을 완화했어요. 압축기로 갑작스러운 피크를 줄이고, 음소거를 켜면 재생 중인 소리도 잦아들어요.
모바일 비율판 영역 폭에 좌우 여백 20px가 포함되어, CSS가 가로만 줄일 수 있었어요.실제 그림을 놓을 수 있는 폭과 높이로 계산해요. 작은 화면에서도 판 전체가 같은 비율로 들어가요.
작은 화면 하단320px 폭에서 포자 3개와 별 표시가 겹칠 수 있었어요.포자 아이콘을 조금 줄이고 별과 설명을 위아래로 배치해요.
스테이지 탐색긴 장 목록을 직접 내려야 했어요.20개 장 바로가기와 이어하기 버튼을 넣었어요. 다음 미완료 판에 테두리를 표시해요.
선택과 발사터치는 두 번, 마우스는 한 번만 눌러도 발사되어 안내와 달랐어요.별도 발사 버튼을 없앴어요. 첫 입력은 미리보기, 같은 컵케익을 다시 누르면 발사해요. 드래그하면 지나간 친구들이 반응하고 마지막 친구가 선택돼요. 손을 뗄 때는 발사하지 않으며, 밖에 놓거나 입력이 취소되면 선택을 풀어요. Esc로도 선택을 해제할 수 있어요.
동작 줄이기OS 설정을 켜도 포자 이동과 입자 효과가 계속 나왔어요.큰 이동과 입자는 생략하고 접촉 지점에 잠깐 표시해요. 판정 순서와 손님 타이밍은 같아요.
대기 중 떨림 · 10/20 추가 수정대기 중에도 그림의 크기와 위치가 바뀌고, 좀비 옆의 친구와 서리 상태 레몬은 빠르게 떨었어요.생각하는 동안 그림과 발을 고정해요. 실제로 닿았을 때는 420ms 안에 살짝 눌렸다 돌아와요. 커서나 손가락이 들어올 때는 300ms 동안 한 번 움찔하고 멈춰요. 같은 칸에 계속 있어도 반복하지 않아요. 감염 색상도 같은 위치에 겹쳐 윤곽이 두 겹으로 떨리지 않아요.
설명에 따른 판 이동 · 10/20 추가 수정기본 안내와 맛 설명의 줄 수가 달라지면 쟁반과 배경이 위아래로 움직였어요.설명은 항상 세 줄 높이를 확보하고 긴 내용은 그 안에서 스크롤해요. 판 공간은 내용 크기와 독립적으로 계산하고, 같은 크기의 캔버스는 다시 초기화하지 않아요.
쓸어서 고르기 · 10/20 추가 수정선택하면 발사 버튼이 설명 위에 뜨고, 터치 드래그는 무시했어요.버튼 대신 선택한 컵케익을 다시 눌러 발사해요. 빠르게 쓸어도 중간에 지난 친구들이 차례로 움찔해요. 누른 채 쓸 때만 작은 음이 나고, 연속 음은 간격을 두어요. 대기 중에는 계속 움직이지 않고 동작 줄이기 설정도 유지해요.
버튼 탄성 · 10/20 추가눌림과 복원이 약했어요.커서를 올리면 조금 커지고, 누르면 넓고 납작해져요. 손을 떼면 340ms 동안 늘어났다 돌아와요. 버튼 동작은 즉시 한 번만 실행돼요. 드래그·취소·비활성 버튼은 반동을 생략하고, 빠르게 다시 누르면 이전 반동을 끊어요.
컵케익 수집맛을 모아서 보는 화면이 없었어요.판을 깨면 시작 진열대의 맛을 모두 얻어요. 포장된 맛과 민트초코도 포함해요. 기존 스테이지 별 기록에서 복원하며, 새로 깨는 오늘의 퍼즐도 반영해요. 기존 오늘의 퍼즐 기록은 판 정보가 없어서 소급하지 않아요.
카드 표현카드가 없었어요.12가지 맛을 모아요. 그 맛이 나온 판의 최고 별 1·2·3개를 종이·금박·오로라 표현에 연결했어요. 앞면은 신선, 뒷면은 좀비예요. 민트초코는 양면 모두 신선해요. 전용 좀비 그림이 없는 맛은 게임의 공통 좀비 그림을 사용해요. 경험치나 별 소모는 없어요.
카드 만지기카드가 없었어요.클릭하면 뒤집히고, 커서·손가락을 따라 최대 7도 기울며 빛이 움직여요. 12px 이상 끌면 뒤집지 않아요. 대기 중에는 흔들지 않고, 동작 줄이기 설정에서는 기울임·회전 전환을 생략해요. Enter·Space로 뒤집고 Esc로 닫아요.

컵케익 도감과 카드

시작 화면과 스테이지 목록의 도감 버튼으로 열어요. 클리어 보상에서도 새 카드와 더 높은 별의 카드를 바로 확인할 수 있어요. 중복 카드는 늘어나지 않고 최고 별을 유지해요. 참고 영상의 기울임·뒤집기·금박·오로라를 게임의 종이 질감과 갈색 선에 맞췄어요.

수집 해금·중복·최고 별·기존 저장 복원은 Node 검사로 확인했어요. 브라우저에서는 기존 기록 복원, 블루베리 새 획득과 금박→오로라 업그레이드, 민트 양면, 다시 열어도 저장 유지, 드래그와 키보드, 320×568·390×844 배치를 확인했어요. iOS 실기기 입력감은 별도 확인이 필요해요. 관련 파일: src/collection.js, src/collection.css, src/ui-interactions.js. 검사: node tools/test-collection.cjs, node tools/test-ui-interactions.cjs.

기본 빌드·규칙 검사는 Node만 필요해요. 브라우저 검사는 Playwright와 Chromium, 원본 이미지 재변환은 sharp, 엑셀 재작성은 Codex의 스프레드시트 런타임을 사용해요. 검토용 플레이 파일은 모든 판으로 바로 이동하며 별도의 진행 저장을 써요. 일반 게임 파일은 순서대로 잠금이 풀려요.

전달 상태

변경은 별도 브랜치와 검토용 PR에 담아요. 검토용 웹은 studio-penumbra.com/cupcake-zombie-preview/에 공개되어 있고, 기존 게임과 진행을 따로 저장해요. 앱스토어 제출과 iOS 실기기 검사는 별도로 남아 있어요. 이 문서의 화면과 수치는 첨부된 검증 결과를 기준으로 작성했어요.
